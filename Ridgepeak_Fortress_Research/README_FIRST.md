# Fortress Acquisition Intelligence: independent research + engineering source packet

Date: November 4, 2026

## Purpose
Prepared as an independent application work sample for Ridgepeak Partners Investment Analyst role, with residential service sector targeting informed by public Fortress Service Partners materials. This is not an actual acquisition process or an engagement by Ridgepeak.

## Deliverables

- `Acquisition_Pipeline_Executive_Brief.pdf`: first-pass market and sourcing recommendation.
- `Conditional_Investment_Committee_Memorandum.pdf`: conditional, no-price investment screening of a publicly identified operator.
- `Transaction_Execution_Playbook.pdf`: owner qualification, nonbinding hypothetical LOI topic framework, diligence and integration.
- `Fortress_Illustrative_Acquisition_Underwriting.xlsx`: fully formula-driven sample deal model with scenario cases, entry equity, five-year cash waterfall, 5x5 sensitivity and model checks.
- `screening_pipeline_30.csv`: thirty real publicly identifiable company descriptions and source links.
- `evidence_register.csv`: first-party citations and exact verification limitations.
- `formula_engine_reference_tests.json`: model-engine precision and scenario expected values for software tests.
- `model_formula_audit.json`: automated workbook formula and input-precision audit.
- `research_manifest.json`: research scope and key sector sources.
- `CLAUDE_ENGINEERING_HANDOFF.md`: implementation requirements for Claude Code.

## Quality control

The model has 291 formula cells. The XML audit found no calculated output hardcoded as a number and no financial assumptions exceeding two decimal places. Ten financial-model integrity checks pass at the base case. Every real company remains an uncontacted, financially unverified research lead.

## User next step

Unzip the bundle into a local project directory and launch Claude Code in that directory. Paste the engineering prompt from the ChatGPT conversation. Claude Code is responsible for implementation only; ChatGPT owns investment research and recommendations.
